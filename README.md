# johannaalbers.github.io

Personal site of Johanna Albers, MSc Health Data Science candidate (URV, 2025 to 2027).

Live at [johannaalbers.github.io](https://johannaalbers.github.io).

Built with [Beautiful Jekyll](https://github.com/daattali/beautiful-jekyll) and hosted on GitHub Pages.

## Structure

| Path | Contents |
|---|---|
| `index.html` | Home page, blog feed |
| `aboutme.md` | Background, education, experience |
| `projects.md` | Selected data science projects, linked to their repositories |
| `_posts/` | Blog posts |
| `_config.yml` | Site configuration |
